# Week of 2026-04-27 to 2026-05-03

**Window:** 2026-04-27 00:00:00 to 2026-05-03 23:59:59, local author time
**Recapped:** 2026-08-28
**Commits in window:** 141 (109 non-merge, 32 merges)

This is a backfill written **117 days after the window closed**. It is an
unusually large week: the measured commit/body/stat read was about 12.6k
tokens. Work spanned the final Airflow cutover, dbt/DuckDB and dashboard
migrations, n8n decommissioning, portfolio presentation, and a new production
observability stack.

## What shipped

[Plan 71](../plans/plan_71_airflow.md) closed the remaining scraper migration
and processing-test gap at `e95e426`: scheduled listing and detail DAGs, safe
claim release, a scraper readiness endpoint, 52 processing integration tests,
95% processing unit coverage, and dashboard visibility into Airflow. This made
the orchestrator thin and kept business behavior in tested services.

The surrounding unattributed work completed the same architectural turn.
`421f90c` replaced dbt-backed operational views with plain Postgres views over
HOT tables. `9f08336` rebuilt dbt on DuckDB/MinIO silver, replaced Python
integration seeding with declarative dbt unit tests, and overhauled CI.
`db85b2a` and its follow-ups converted the Streamlit dashboard into an
analytics product reading DuckDB materializations instead of operational
Postgres queries.

[Plan 86](../plans/plan_86_grafana.md) added Prometheus and Grafana at
`3b84995`, with Airflow, Postgres, MinIO, service and host metrics provisioned
as code. Later commits added Loki/Promtail aggregation, customer-pipeline
gauges, dashboards, Telegram alerts and operational fixes. The plan's purpose
was to add observability only after Airflow supplied meaningful production
signals to observe.

`850cdb9` names [Plans 102](../plans/plan_102_decommission.md) and
[95](../plans/plan_95_portfolio_landing_page.md). It removed n8n, legacy
Postgres and dead service paths while turning `/info` into a concise portfolio
landing page. Follow-ups removed stale tests and mounts, polished the page and
demo, and added data-health metrics. Plan 103 appears only in that commit's
body after the subject has already attributed the commit to Plans 102 and 95,
so it is not an additional attribution under this recap's rule.

The rest of the week repaired issues exposed by the migration: Flyway ordering
and grants, SRP scheduling, 403 ownership, cooldown events, archiver foreign
keys, VIN collisions, dashboard queries, Caddy/static paths, CI, logging and
alert timing. All are named below rather than disappearing for lack of a plan
number.
