## What shipped

The first half of the week tightened the existing system. Carousel and blocked
cooldown cleanup removed stale work, while SRP scraping gained page-one retry,
Xvfb logging and a curl-cffi plus FlareSolverr path with shared cookie state.
Database grants, dashboard links, access-request email and deployment docs were
repaired alongside it.

Integration testing then expanded in three layers: service SQL smoke tests,
dbt model tests using a real seeded database, and operations API tests covering
stateful behavior. Repeated seed, constraint, schema and assertion fixes made
the suite exercise actual Postgres/dbt behavior rather than mocks.

`b15fbe2` names Plan 89 in its body for the operational/analytics split and
Plan 92 for safe service draining. It laid the Airflow foundation, separated
processing ownership from scraping, refactored archiving, and documented the
readiness contract needed to avoid interrupting in-flight work. Neighboring
commits added the first operational tables, processing service, orphan and
artifact cleanup DAGs, dbt-build DAG and further architecture planning. Those
neighbors remain unattributed because their own text does not name a plan.
