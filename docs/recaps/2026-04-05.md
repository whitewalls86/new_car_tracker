redeploy path with operational ownership separated from scraping: the admin

n8n execution state moved into the database, and the scraper was reduced to

workflow gates, health polling, redeploy script and service health endpoints

be unlisted without forcing a full dbt rebuild. In the planning index, that
dbt correction and the service-health gate were recorded as completed Plans

therefore remain unattributed under this recap's rule.

tests and reported full coverage of its application module; database access
moved into a shared helper; ops gained deploy, admin and model coverage; and
the scraper received 184 tests anchored to the n8n API contract. A final
browser-impersonation update followed the scraper suite.
